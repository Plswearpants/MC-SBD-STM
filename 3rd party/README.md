# Third-party packages

`init_sbd` addpaths this folder via `genpath`. Domain code lives in `lib/`, not here.

| Package | Path | Notes |
| --- | --- | --- |
| slanCM | `3rd party/slanCM/` | Colormaps |
| imshow3D | `3rd party/imshow3D/` | 3D slice viewer |
| mat2im | `3rd party/mat2im/` | Matrix → RGB |

Each package keeps its own license file.
